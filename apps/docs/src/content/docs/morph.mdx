<Section id="start" title="Get started">

A morph switches between **states**: ordinary elements laid out where they should appear. One state is visible at a time. When you switch, a single shape animates from the visible state to the next one, and then the next state takes its place.

<Step>

**Install.**

<Install pkg="@fluidkit/core" />

<Step>

**Lay out both states** where they should appear. Hide the panel with `visibility: hidden` (not `display: none`, so it can be measured) and put it above the button with `z-index: 2`. Style the states however you like; here both are [Liquid Blur](/blur) glass.

```html
  <button id="more" class="lb" type="button" aria-controls="panel" aria-expanded="false">More</button>
  <div id="panel" class="lb">
    <p>Panel content</p>
    <button id="close-panel" type="button">Close</button>
  </div>
</div>

<style>
  .morph-scene { position: relative; min-height: 240px; }
  #more { width: 88px; height: 44px; border-radius: 22px; }
  #panel {
    position: absolute;
    left: 0;
    top: 0;
    width: min(280px, 100%);
    height: 220px;
    box-sizing: border-box;
    padding: 20px;
    border-radius: 28px;
    visibility: hidden;
    z-index: 2;
  }
</style>
```

</Step>
<Step>

**Create the morph** once the elements are in the DOM, and call `to()` from your handlers. Accessibility details like `aria-expanded`, Escape and focus are up to you; `onStart` and `onRest` are good places for them.

```ts
import "@fluidkit/core/style.css"; // the glass, if the states are glass
import { createMorph } from "@fluidkit/core";

const button = document.getElementById("more")!;
const panel = document.getElementById("panel")!;
const close = document.getElementById("close-panel")!;

const morph = createMorph({
  states: [button, panel],
  onStart(to) {
    button.setAttribute("aria-expanded", String(to === panel));
    // The panel is already interactive while it animates in
    if (to === panel) close.focus({ preventScroll: true });
  },
  onRest(at) {
    if (at === button && panel.contains(document.activeElement)) button.focus({ preventScroll: true });
  },
});

const toggle = () => morph.to(morph.current === panel ? button : panel);
const back = () => morph.to(button);
const onKey = (e: KeyboardEvent) => e.key === "Escape" && back();
button.addEventListener("click", toggle);
close.addEventListener("click", back);
document.addEventListener("keydown", onKey);

// On unmount:
// button.removeEventListener("click", toggle);
// close.removeEventListener("click", back);
// document.removeEventListener("keydown", onKey);
// morph.destroy();
```

</Step>

<Step>

**Add the states.** Each `Morph.State` has a `value`. A `Morph.Trigger` switches to its `value` when clicked. A state can also be a trigger: here the button opens the panel.

```tsx
import "@fluidkit/react/style.css"; // the glass, if the states are glass
import { Morph } from "@fluidkit/react";

export function More() {
  return (
    <div className="morph-scene">
      <Morph.Root>
        <Morph.State value="button" id="more" className="lb" render={<Morph.Trigger value="panel" />}>
          More
        </Morph.State>
        <Morph.State value="panel" id="panel" className="lb">
          <p>Panel content</p>
          <Morph.Trigger value="button">Close</Morph.Trigger>
        </Morph.State>
      </Morph.Root>
    </div>
  );
}
```

```ts
import { createMorph } from "@fluidkit/core";

const share = document.getElementById("share")!;
const panel = document.getElementById("share-panel")!;
```

<Fragment slot="react">

```tsx
import { useCallback, useEffect, useState } from "react";
import { Morph } from "@fluidkit/react";

const items = ["Messages", "Copy Link", "Add to Favorites"];

export function Share() {
  const [value, setValue] = useState("share");
  const open = value === "panel";
  useEscape(useCallback(() => setValue("share"), []));
  return (
    <div className="scene">
      <Morph.Root value={value} onValueChange={setValue}>
        {/* The pill is also a trigger: clicking it opens the panel */}
        <Morph.State
          value="share"
          id="share"
          aria-haspopup="menu"
          aria-expanded={open}
          render={<Morph.Trigger value={open ? "share" : "panel"} />}
        >
          <ShareIcon /> Share
        </Morph.State>
        <Morph.State value="panel" id="share-panel" role="menu" aria-label="Share">
          {items.map((label) => (
            // Choosing an item closes the panel
            <Morph.Trigger key={label} value="share" role="menuitem">
              <Icon name={label} /> {label}
            </Morph.Trigger>
          ))}
        </Morph.State>
      </Morph.Root>
    </div>
  );
}

/** Escape closes the panel */
function useEscape(back: () => void) {
  useEffect(() => {
    const onKey = (e: KeyboardEvent) => e.key === "Escape" && back();
    document.addEventListener("keydown", onKey);
    return () => document.removeEventListener("keydown", onKey);
  }, [back]);
}
```

```ts
import "@fluidkit/core/style.css";
import { createMorph } from "@fluidkit/core";

const sort = document.getElementById("sort")!;
const panel = document.getElementById("sort-panel")!;

const morph = createMorph({
  states: [sort, panel],
  onStart: (to) => sort.setAttribute("aria-expanded", String(to === panel)),
});

sort.addEventListener("click", () => morph.to(morph.current === panel ? sort : panel));

// Picking an option updates the pill label and moves the match to it, then closes
panel.addEventListener("click", (e) => {
  const pick = (e.target as Element).closest<HTMLElement>("[role=menuitemradio]");
  if (!pick) return;
  for (const option of panel.querySelectorAll<HTMLElement>("[role=menuitemradio]")) {
    option.setAttribute("aria-checked", String(option === pick));
    const label = option.querySelector("span")!;
    if (option === pick) label.dataset.fkMatch = "sort";
    else delete label.dataset.fkMatch;
  }
  sort.querySelector("span")!.textContent = pick.textContent!.trim();
  morph.to(sort);
});
document.addEventListener("keydown", (e) => {
  if (e.key === "Escape") morph.to(sort);
});
```

```ts
import { createMorph } from "@fluidkit/core";

const dot = document.getElementById("dot")!;
const bar = document.getElementById("bar")!;
const card = document.getElementById("card")!;
const states = [dot, bar, card];

const morph = createMorph({
  states,

      const target = to === dot ? dot : to.querySelector<HTMLElement>("#expand, #collapse");
```

<Section id="options" title="Options" only="js">

`createMorph(options: MorphOptions): Morph`

| Option | Description |
| --- | --- |
| `states: HTMLElement[]` | The state elements. Each must be in the DOM, laid out where it should appear |
| `initial?: HTMLElement` | The state shown first. Default: the first one |
| `container?: HTMLElement` | Where to put the shape while it animates. Use it when a state's parent has `overflow: hidden` and would clip the shape. Default: next to the smaller state |
| `spring?: { grow?, shrink? }` | Springs for growing into a larger state and shrinking into a smaller one. Default: `defaultMorphSprings` |
| `onStart?: (to, from) => void` | Called when an animation starts, including when it reverses or changes target mid-way |
| `onRest?: (at) => void` | Called when the animation finishes |
| `onProgress?: (progress, to, from) => void` | Called every frame with progress toward `to`, from `0` to `1`. `from` is `null` if the animation was redirected mid-way. Called once with `1` when the switch is instant |

Each direction has five spring channels: `x` and `y` for the position, `width` and `height` for the size, and `progress` for corners, content and shared elements. Pass only the ones you want to change. A spring is `{ duration, bounce, settle? }`: `duration` in seconds, `bounce` from `0` (no overshoot) to `1`, and `settle`, the bounce after the first overshoot (default: same as `bounce`).

```ts
const morph = createMorph({
  states: [button, panel],
  spring: {
    grow: { y: { duration: 0.4, bounce: 0.3, settle: 0.1 } },
  },
});
```

Use `onProgress` to animate something else in sync, like a backdrop or a chevron:

```ts
const morph = createMorph({
  states: [button, panel],
  onProgress(progress, to) {
    const open = to === panel ? progress : 1 - progress;
    scrim.style.opacity = String(open);
  },
});
```

<Section id="api" title="API" only="js">

| Member | Description |
| --- | --- |
| `current` | The target state. Changes as soon as you call `to()` |
| `moving` | `true` while animating |
| `to(state, move?)` | Animates to `state`. Returns a `Promise<boolean>`: `true` when it arrives, `false` if it was redirected or destroyed first. Pass `{ instant: true }` to switch without animation |
| `update()` | Re-measures the states. Call it if something moves a state while it animates |
| `add(state)` | Adds a state, hidden until you switch to it. Useful for list items added later |
| `remove(state)` | Removes a state and restores its inline styles. Call it before removing the element from the page. You can't remove the current state |
| `set(settings)` | Updates `spring`, `onStart`, `onRest` or `onProgress` without recreating the morph. New springs apply from the next animation |
| `destroy()` | Stops the animation, removes the shape and restores every state's inline styles |

The morph follows scrolling, window resizes and size changes of the states on its own. `destroy()` doesn't remove event listeners you added.

<Only react>

<Section id="layout" title="How it works">

<Rows>
<Row>
<Cell title="The larger state">

The real element animates, using only its inline `transform`, `opacity`, `filter` and `clip-path`. Its text doesn't reflow, and it stays interactive while it moves. Don't put transitions on those properties. A translation of your own, like `translate: -50% -50%`, is kept. It must sit above the shape (`z-index: 2`).

</Cell>
<Cell title="The smaller state">

A snapshot of it rides inside the shape and fades out. The snapshot keeps the element's classes and attributes, but not its parents, so don't style states through parent selectors.

</Cell>
</Row>
<Row>
<Cell title="Surfaces">

The shape uses the larger state's background, border and shadow. If the smaller state looks different, its look fades out as the shape grows: a solid button dissolves into glass.

</Cell>
<Cell title="Corners">

Each corner animates from one state's radius to the other's. A panel rounded only at the top stays square at the bottom. Where `corner-shape` is supported, it animates too.

</Cell>
</Row>
<Row>
<Cell title="Hidden states">

Hidden states get `opacity: 0`, `visibility: hidden` and `data-fk-away`, and ignore clicks. A state that has focus when it hides stays focusable, so screen readers still announce it. Clicking the moving shape clicks the state underneath, so a button can be pressed again before the animation ends.

</Cell>
<Cell title="Mounting">

Safe to import on the server. Create the morph in the browser after mount, and call `destroy()` on unmount. The shape exists only while animating, so selectors like `:last-child` work as usual. With reduced motion, states switch instantly.

</Cell>
</Row>
</Rows>

</Section>

<Section id="top-layer" title="Dialogs and popovers">

A state can be a `<dialog>` or a popover. Open it before switching to it, so it can be measured, and close it after switching back:

```ts
const morph = createMorph({ states: [button, dialog] });

button.addEventListener("click", () => {
  dialog.showModal(); // or dialog.show(), panel.showPopover()
  morph.to(dialog);
});
close.addEventListener("click", async () => {
  // `false` if it was redirected on the way; then keep it open
  if (await morph.to(button)) dialog.close();
});
```

Dialogs and popovers render in the top layer, above everything else, including the shape. Fade the backdrop in with the animation so the shape isn't dimmed early:

```ts
const morph = createMorph({
  states: [button, dialog],
  onProgress(progress, to) {
    dialog.style.setProperty("--open", String(to === dialog ? progress : 1 - progress));
  },
});
```

```css
dialog::backdrop { opacity: var(--open, 1); }
```

<Only react>

In React, open the dialog in the trigger's `onClick`, before switching, and close it when `to()` resolves:

```tsx
import { useMergedRefs } from "@fluidkit/react";

const morph = useMorph({ defaultValue: "button" });
const dialog = useRef<HTMLDialogElement>(null);
const dialogRef = useMergedRefs(dialog, morph.state("dialog"));

<button ref={morph.state("button")} onClick={() => { dialog.current!.showModal(); morph.to("dialog"); }}>Open</button>
<dialog ref={dialogRef}>
  <button onClick={async () => (await morph.to("button")) && dialog.current!.close()}>Close</button>
</dialog>
```

</Only>

<Only vue>

In Vue, open the dialog in the click handler, before switching, and close it when `to()` resolves:

```vue
<script setup lang="ts">
import { shallowRef } from "vue";
import { useMorph } from "@fluidkit/vue";

const morph = useMorph({ defaultValue: "button" });
const dialog = shallowRef<HTMLDialogElement | null>(null);
// One ref for both: the dialog element, and the morph's state
const toDialog = morph.state("dialog");
const dialogRef = (el: unknown) => {
  dialog.value = el as HTMLDialogElement | null;
  toDialog(el);
};
const open = () => {
  dialog.value!.showModal();
  morph.to("dialog");
};
const close = async () => (await morph.to("button")) && dialog.value!.close();
</script>

<template>
  <button :ref="morph.state('button')" @click="open">Open</button>
  <dialog :ref="dialogRef">
    <button @click="close">Close</button>
  </dialog>
</template>
```

</Only>
<Only svelte>

In Svelte, open the dialog in the click handler, before switching, and close it when `to()` resolves. `bind:this` and the state's attachment sit side by side:

```svelte
<script lang="ts">
  import { useMorph } from "@fluidkit/svelte";

  const morph = useMorph(() => ({ defaultValue: "button" }));
  let dialog = $state<HTMLDialogElement>();

```

</Only>

A popover with `popover="auto"` closes on any click outside it, including on the moving shape. Use `popover="manual"` and close it yourself.

<Section id="glass" title="With Liquid Blur">

When a state is inside a Liquid Blur [glass group](/blur#groups), the behavior depends on where the other state is:

- **Next to the other buttons:** the shape stays in the group and merges with the neighboring glass as it moves.
- **On top of them:** the shape leaves the group and animates as separate glass above it (`z-index: 1`). The gap it leaves in the group closes smoothly.

If a parent has `overflow: hidden`, the shape would be clipped. Pass a `container` to place it elsewhere; it then inherits theme and CSS variables from that container.

</Section>

<Section id="support" title="Browser support">

Any browser with ES2022 and `clip-path: inset()`. Corner shapes animate where `corner-shape` is supported; elsewhere corners stay round.

</Section>

<Section id="limitations" title="Limitations">

- Rotated or scaled ancestors aren't supported. The larger state can't have its own transform other than a translation.
- The larger state enters scaled up to 1.45×. To keep it from widening the page, the morph sets `overflow-x: clip` on the nearest full-width ancestor (like `main`) while animating. If the states sit directly in `<body>`, wrap them in an element with `overflow-x: clip` yourself; on `<body>` it doesn't help in iOS Safari.
- The smaller state is a snapshot: video and inputs inside it don't update during the animation.
- The larger state's `::before` and `::after` stay visible while it animates.
