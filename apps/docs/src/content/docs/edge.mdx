<Section id="start" title="Get started">

Scroll Edge is part of the [Liquid Blur](/blur) stylesheet, so there's nothing else to install. It doesn't need glass: it works on any scrolling element.

<Only js>

<Steps>
<Step>

**Install.**

<Install pkg="@fluidkit/core" />

</Step>
<Step>

**Import the stylesheet** once, before your own styles.

```ts
import "@fluidkit/core/style.css";
```

</Step>
<Step>

**Add `lb-edge` to the scrolling element.** No script or extra markup.

```html
<ol class="songs lb-edge">…</ol>

<style>
  .songs { overflow-y: auto; }
</style>
```

</Step>
</Steps>

</Only>
<Only react>

<Steps>

</Step>
<Step>

**Add `lb-edge` to the scrolling element.** No script or component.


</Step>
</Steps>

<Section id="examples" title="Examples">

### A list and a row of chips

The list fades at the top and bottom, the chips at the sides. At the start of a scroll there's no fade on that side; it appears as content goes under the edge. At the end, the last fade disappears, so the last item is never covered.

<EdgeExample />

```html
<div class="lb card">
  <div class="chips lb-edge-x">…</div>
  <ol class="songs lb-edge">…</ol>
</div>
```

```css
.songs { overflow-y: auto; overscroll-behavior: contain; }
.chips { overflow-x: auto; --lb-edge-size: 20px; }
```

### Under a sheet title

The list in [Drag's sheet](/drag#examples) uses `lb-edge`: rows fade out under the title as they scroll, and the first row isn't faded at the top.

</Section>

<Section id="options" title="Options">

| Class or variable | Description |
| --- | --- |
| `lb-edge` | Fades the top and bottom, for vertical scrolling |
| `lb-edge-x` | Fades the left and right, for horizontal scrolling |
| `--lb-edge-size` | Length of the fade, and how much scrolling it takes to appear. Default: `28px`. Inherited |
| `--lb-edge-start`, `--lb-edge-end` | The same for one side: top (or left) and bottom (or right). Default: `--lb-edge-size`. `0px` turns that side off |
| `--lb-edge-strength` | How transparent content gets at the edge. Default: `1` (fully); `0.5` is half |

```css
/* A chat: newest messages at the bottom, so only the top fades, and further */
.messages { --lb-edge-start: 48px; --lb-edge-end: 0px; }

/* Keep text slightly readable under the edge */
.notes { --lb-edge-strength: 0.6; }
```

</Section>

<Section id="how" title="How it works">

<Rows>
<Row>
<Cell title="A mask">

The fade is a `mask` on the scrolling element: content goes from opaque to transparent right at the edge. Since it fades rather than paints over, it works on glass, photos and plain backgrounds alike.

</Cell>
<Cell title="Driven by scroll">

Each fade is as long as the content hidden past that edge, up to `--lb-edge-size`. It grows as content scrolls under the edge and shrinks to nothing at the end. Scroll-driven animations handle this, momentum included, with no script. If there's nothing to scroll, there's no fade.

</Cell>
</Row>
</Rows>

Put it on the scrolling element, not on glass itself (it would fade the glass too). For example, on a list inside the glass. It uses the element's `mask` and `animation`, so your own values for those would override it.

</Section>

<Section id="support" title="Browser support">

Any browser with scroll-driven animations and `@property`: Chrome and Edge 115, Safari 26. Elsewhere (Firefox) there's simply no fade.

</Section>

<Section id="limitations" title="Limitations">

- The scrolling element's own `mask` and `animation` are replaced.

</Section>
